# screenShotik (Megagroup) for Linux

Нативный клиент скриншотов Megagroup для Linux с поддержкой Wayland (Hyprland, Omarchy, Sway) и X11.

## Возможности
- Точная копия оригинального Windows-клиента Megagroup
- Корпоративная палитра `#BC0000`
- Полный набор инструментов (стрелки, рамки, текст, маркер, номера)
- Мгновенная загрузка на `https://o525.ru/upload`
- Автоматическое копирование ссылки в буфер обмена (`wl-copy` / X11)
- Автосохранение снимка на диск
- Интеграция с горячими клавишами рабочего стола

## Горячие клавиши
- `Shift + F1` или `Print` — интерактивный оверлей выделения области и рисования
- `Print` или `Ctrl + Print` — снимок экрана
- В оверлее: `Ctrl + Enter` — сохранить на сервере и скопировать ссылку
