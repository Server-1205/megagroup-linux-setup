Установлена версия

История изменений:

Версия 0.2.4 - 11.10.2018

  • MacOs: восстановлена, сломанная поддержка нескольких мониторов
  • Добавлены координаты левого верхнего угла выделенной области
  • В режиме выделения области, можно нажать Пробел и область станет такой же, как в последний раз на этом мониторе
  • Подсказка в режиме выделения

Версия 0.2.3 - 08.08.2018

  • Electron 2.0.5
  • Исправлено: Положение панели, при замене основного монитора на монитор с другим разрешением
  • Исправлено: При быстром переключении alt-tab, после окончания редактирования скриншота, он мог не успеть отправиться на сервер
  • Инструмент "текст": шаг увеличения размеров, центровка по вертикали относительно середины, курсор по умолчанию - стрелка

Версия 0.2.2 - 21.05.2018

  • Electron 2.0
  • Исправлено - Win7 - падения при нестандарном увеличение шрифтов
  • PrintScreen - по умолчанию выключен
  • Управление короткими клавишами из меню

Версия 0.2.1 - 14.05.2018

  • Нумерованный прямоугольник работает как нумерованный кружок, если нажать и отпустить кнопку мыши
  • Под win добавлена короткая клавиша - PrintScreen

Версия 0.2.0 - 11.04.2018

  • Win: Клик левой кнопкой мыши на иконке в трее делает скриншот
  • Местоположение панели для каждого монитора сохраняется отдельно
  • Обновление без запроса - включено по умолчанию
  • Добавлен пункт меню, который показывает лог фаил в папке

Версия 0.1.9 - 10.04.2018

  • Любые символы в названии папки сохранения
  • Проверка на обновления: не чаще раза в сутки
  • Минимальная длина логина: два символа

Версия 0.1.8 - 30.03.2018

  • В разы улучшена скорость снятия скриншота
  • Короткие клавиши для linux shift+F1 и shift+F12 (должны работать вместе с "ПунтоСвитчерами")
  • Должна работать ctrl+z так же как backspace
  • Обновлен электрон до 1.8.4
  • Настройка, позволяющая переключится на другую программу, а потом вернуться к редактированию скриншота
  • Инструмент Карандаш
  • Ошибка - Win7 150%
  • Режим автоматического обновления с минимумом вопросов - опция

Версия 0.1.7 - 20.03.2018

  • Локальная история (альфа WIN7-нужен фидбэк)
  • Кнопка для копирование скриншота в буфер картинкой
  • Настройка для автосохранения всех скриншотов на диске (в папке сохранения будут дополнительные папки с датами)
  • Обновлен электрон до 1.8.3
  • Прямоугольники позиционируются по внутренним углам
  • Настройка для включение логирования в фаил
  • Выключены тени у прямоугольников
  • Новая панель инструментом (Горшкова Анастасия, Велькин Андрей, Мирошниченко Александр)
  • Масштаб в Linux mint с двумя мониторами
  • Проверка обновления при старте, только по запросу

Версия 0.1.6 - 05.03.2018

  • Автозапуск включен по умолчанию
  • Если при измении размера выделенной области зажать кнопку shift, область можно подвинуть
  • Колесо мышки изменяет толщину
  • Отображается размер выделенной области
  • Групповое выделение объектов для изменение цветов и толщины(кроме закращенного прямоугольника), удаления и перемещения
  • Настройка толщины каждого инструмента сохраняется отдельно
  • Инструмент нумерованный прямоугольник
  • Инструмент закрашенный прямоугольник (вместо размытия). Цвет сохраняется отдельно.

Версия 0.1.5 - 23.02.2018

  • Инструмент линия
  • Инструмент эллипс
  • Инструмент отключение/включение выделения
  • Если в режиме выделения нажать Enter, выделение выключится

Версия 0.1.4 - 21.02.2018

  • Уведомления
  • Настройка "открывать в браузере".(Чтобы работало, один из браузеров должен быть настроен браузером по умолчанию)
  • shift+ctrl+enter или shift+cmd+enter сохраняет фаил на диск
  • linespacing у текстового инструмента изменен с 0.8 до 1
  • Win, Mac Прогресс закачки обновления
  • Win, Mac Отмена обновления
  • История изменений
  • Поддержка win32bit
  • Поддержка linux32bit
  • MacOs Windows, клик правой кнопкой на иконке - создает скриншот
  • Linux клик левой кнопкой на иконке - создает скриншот. Правая кнопка - меню
